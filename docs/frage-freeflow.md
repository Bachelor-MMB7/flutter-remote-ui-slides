# Frage: Warum nicht FreeFlow?

> FreeFlow führt Beschreibung und Daten auf dem Server zusammen, meine Screens
> halten ihren Zustand auf dem Gerät. Und die Server-Seite läuft dort in
> TypeScript mit Node.js — mein Server ist in Dart und kompiliert die
> Definitionen mit derselben RFW-Bibliothek, mit der der Client sie rendert.

Gegenüberstellung, kein Ausschluss: nicht „FreeFlow fiel weg, **weil** ich Dart
wollte". Der Dart-Server ist laut Kap. 6-1 eine Folge der RFW-Wahl („written in
Dart **as well**"), kein Auswahlkriterium.
