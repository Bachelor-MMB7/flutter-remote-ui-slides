# Demo und Evaluation nach Peffers

> Die Demo zeigt einen Fall des Problems und dass es funktioniert. Die Evaluation
> vergleicht die Ergebnisse mit den Zielen, die ich vorher festgelegt habe.

## Peffers' Wortlaut (Kap. 2-3)

**Aktivität 4, Demonstration:** *"demonstrates the **utility** of the artifact by
applying it to one or more concrete instances of the problem"*

**Aktivität 5, Evaluation:** *"assesses the **effectiveness** of the artifact by
comparing the actual demonstration results **against the objectives defined in
Activity 2**"*

| | Frage | Schlüsselwort |
|---|---|---|
| Demo | Lässt es sich auf das Problem anwenden? | Nützlichkeit |
| Evaluation | Erfüllt es die Ziele aus Aktivität 2? | Wirksamkeit |

Aktivität 2 ist bei mir Abschnitt 1-4, also **SO1 bis SO3**. Deshalb steht die
SO-Zeile auf jeder Befundfolie — sie ist das Ziel, gegen das verglichen wird.
Ohne sie wäre es keine Evaluation nach Peffers, sondern nur eine Messung.

## Formulierungen

**Nicht sagen:** „Die Evaluation zeigt, so muss es gehen." Sie schreibt nichts
vor, sie vergleicht.

**Nicht sagen:** „Die Demo beweist, dass es funktioniert." Ein Durchlauf ist eine
Anekdote — belegt wird es in der Evaluation.

**Genauer als „Anforderungen":** Ziele oder Sub-Objectives. Peffers sagt
"objectives", und die SOs sind die messbare Form der Anforderungen aus Kap. 5.
